# The keyboard

Everything below works while the page is open. The same keys work in Final Draft.

## Moving between elements

| Key | From | To |
|---|---|---|
| <kbd>Enter</kbd> | scene heading | action |
| <kbd>Enter</kbd> | action | action |
| <kbd>Enter</kbd> | character | dialogue |
| <kbd>Enter</kbd> | dialogue | character |
| <kbd>Enter</kbd> | parenthetical | dialogue |
| <kbd>Tab</kbd> | action (empty line) | character |
| <kbd>Tab</kbd> | character (empty) | transition |
| <kbd>Tab</kbd> | dialogue (empty) | parenthetical |
| <kbd>Tab</kbd> | end of a filled line | the next element along |

Typing `int.`, `ext.` or `est.` at the start of an action line turns that line into a
scene heading by itself.

## Forcing an element

| Key | Element |
|---|---|
| <kbd>Ctrl</kbd>/<kbd>Alt</kbd> + <kbd>1</kbd> | Scene heading |
| <kbd>Ctrl</kbd>/<kbd>Alt</kbd> + <kbd>2</kbd> | Action |
| <kbd>Ctrl</kbd>/<kbd>Alt</kbd> + <kbd>3</kbd> | Character |
| <kbd>Ctrl</kbd>/<kbd>Alt</kbd> + <kbd>4</kbd> | Parenthetical |
| <kbd>Ctrl</kbd>/<kbd>Alt</kbd> + <kbd>5</kbd> | Dialogue |
| <kbd>Ctrl</kbd>/<kbd>Alt</kbd> + <kbd>6</kbd> | Transition |

## The rest

| Key | Does |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Ctrl</kbd> + <kbd>Y</kbd> | Undo / redo, across structure |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | Save now (it also saves as you type) |
| <kbd>Alt</kbd> + <kbd>J</kbd> | Note on this line — never prints, never exports to PDF |
| <kbd>→</kbd> at the end of a name | Accept the suggested character name |
| <kbd>Esc</kbd> | Close the side panel, then close the page |
| <kbd>/</kbd> | Jump to the search box (in the guide) |
