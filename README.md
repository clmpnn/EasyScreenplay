## ✨ Overview

**EasyScreenplay** is a lightweight tool for drafting and formatting screenplays in standard industry style — scene headings, action lines, character cues, dialogue, and transitions — without wrestling with a heavyweight desktop app.

> 💡 *Note: this README is a starter template built from the repo name — swap in the real feature list, screenshots, and stack below once confirmed against the codebase.*

## 🧩 Suggested Features

| Feature | Description |
|---|---|
| 📄 **Auto-Formatting** | Scene headings, action, dialogue, and transitions formatted to standard screenplay conventions as you type |
| 🎭 **Character & Dialogue Blocks** | Smart indentation and casing for character cues and parentheticals |
| 📑 **Scene Navigation** | Jump between scenes in a long script |
| 📤 **Export** | Export to PDF or plain text in industry-standard layout |
| 🖋️ **Distraction-Free Editor** | A clean writing surface focused on the page, not the toolbar |
