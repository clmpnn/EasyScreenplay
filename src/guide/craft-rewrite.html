Finish, rest, rewrite

The day the last beat is drafted · Two weeks of calendar, a few hours of work

Finish it, leave it alone, then one pass per problem — never all at once.

The sequence: rest (≥24 h for a short; 10–14 days for a feature) → passes in order, one job per pass, ≥10 days cooling between major passes on long work → reader notes → pre-flight. (A pass = one full trip through the script fixing only one kind of thing — that focus is the entire trick of rewriting.) Draft and rewrite in different sessions, ideally different days.

Set the number before you start. Stephen King's formula — second draft = first draft minus ten per cent — is arbitrary, and it works. It converts an open-ended activity into a finite one, which is the actual problem with rewriting. A pass that comes out longer than what it started with was a different job than the one you meant to do. (The compression moves that get you there are in Dialogue, subtext, compression.) His other rule belongs here too: write with the door closed, rewrite with the door open — nobody sees a draft until it is finished, and then the right people see it early.

Pass Name The one job tool
0 Print Read One sitting, PDF on a different device, paper notes only. Mark big moves: cut / add / move whole scenes. Never open the file during this pass Export Ctrl+Shift+P to a tablet or printout
1 Structure Execute the structural notes from Pass 0. Move, cut, add whole scenes. Every scene passes the card test Structure Lines ON · Beat Board side-by-side
2 Scene & character Enter later / exit earlier everywhere. Every character has a want in every scene. Character screen-time audit Navigator 2.0 → Characters
3 Dialogue Cover-names test (→ Dialogue, subtext, compression). Anyone saying exactly what they mean? Fix. Cut first lines of speeches on suspicion TTS voices assigned
4 Action lines Split blocks >4 lines. Delete every "we see" / "we hear" / camera direction / inner state. Verbs > adjectives Ctrl+F for "we see," "she is," "he feels" — delete every hit
5 Read-aloud (TTS) Assign distinct voices per character; read the entire script aloud. ScriptNote every line that stumbles; after the read, repair them all Navigator → Characters → assign voices → Tools → Read Script (or your own voice)
6 Reader notes Triage (below). Execute ACCEPT + ADAPT only. One session per reader round Turn revision tracking on from the Production/Revisions menu before you start, so a "fix" that reads worse can be reverted. (Ctrl+R marks a selection as revised — it is not the on/off switch)
7 Pre-flight The The twelve mistakes checklist, every box —

Getting notes that are usable — never send pages with "thoughts?" Send the seven questions:

  1. Where were you bored? (page numbers)
  2. Where were you confused?
  3. What is the story about — one sentence?
  4. Which character would you cut?
  5. Which character do you want more of?
  6. Where did you stop believing a choice or a line?
  7. Did the ending land? Why / why not? (Nothing else. No "did you like it.")

Triage every note:

Verdict Meaning Action
ACCEPT The note is right Execute it exactly
ADAPT Real symptom, wrong cure Fix it your way
REJECT Considered, disagree Write the reason in one sentence. You're allowed to be certain

Two readers flag the same location independently = real problem there, even if their diagnoses differ. One reader prescribing a fix = optional. Healthy-draft ratio ≈ 40 accept / 35 adapt / 25 reject. You're the boss of the draft.

Then: date the title page → save → add to the DONE list. Before ANY external submission, register — the numbers are in the guide.

On the practice page: before a pass, ⧉ Save a copy (Script panel) · Pass 3 → Cover names · Pass 4 → Doctor › Action · Pass 5 → Read aloud, a voice per character, ⚑ on every stumble · Pass 7 → the doctor clean, then the pre-flight.
